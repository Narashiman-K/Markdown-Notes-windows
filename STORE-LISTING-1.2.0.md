## Description

*(max 10,000 characters; this is about 4,300)*

```
Suprasuta Markdown Notes turns Markdown from something you write into something you can read, mark up, compare and think with.

Most editors make you choose between reading and annotating. This one lets you highlight a passage, attach a comment, and still hand the file to someone who has never heard of this app, because every annotation is written into the Markdown itself as a standard HTML tag that GitHub, VS Code, Obsidian and every other renderer already understand.

READ AND ANNOTATE
• Highlight in five colours, underline, strike through, and attach comments
• Annotations are saved inside the .md file: no sidecar files, nothing to lose
• Export your annotations and load them back onto any copy of the document, even an edited one
• Comments panel listing every note, with click-to-jump
• Reader mode (F9): distraction-free reading with text size, line width, spacing and page colours
• Page view shows converted documents at their original page size, with scanned pages beside their text
• Outline panel, find-in-page, zoom, and light, dark or system theme

COMPARE DOCUMENTS
• See every difference side by side or inline, with the changed words marked
• Compare the open document with another file, with its own saved version, or load two files
• Take a change across in either direction, edit either side, or make one match the other
• Export the comparison as a page or Markdown, or ask AI to explain what changed

EDIT WITHOUT LOSING ANYTHING
• Full source editor with Markdown syntax highlighting and line numbers
• Select any text and a formatting bar appears: bold, headings, lists, tables, links, code blocks
• Side-by-side live preview while you type
• AutoSave every 30 seconds, with recovery copies so unsaved work survives a crash
• Several documents open at once, each in its own window
• Opening a file from Explorer never discards your unsaved edits
• Merge several documents into one

WORK WITH YOUR CLOUD FOLDERS
• Open from and save to the folders OneDrive, Google Drive, Dropbox, iCloud and Box keep in sync on your PC
• No sign-in inside the app: your files sync the way they always do

CONVERT ALMOST ANYTHING TO MARKDOWN
Drop a file onto the window, or press Ctrl+Shift+M.

• Documents: PDF, Word (.docx), Excel (.xlsx, .xls), PowerPoint (.pptx), OpenDocument (.odt, .ods), EPUB
• Pictures in PDF, Word, PowerPoint and EPUB files are kept, each where it sits
• EPUB books convert in full, with working contents and index links
• Text and data: TXT, CSV, TSV, JSON, YAML, XML, HTML, RTF, subtitles, and source code
• Scanned PDFs and photos: text read offline on your PC in English, Kannada and Hindi; upside-down pages are turned upright first. Cloud reading is available if you choose it.
• Audio: transcribed via a cloud service

Every document and text format is converted entirely on your own computer. No account, no subscription, no internet connection required.

ASK YOUR DOCUMENTS
An AI panel that stays honest about what it knows.

• Answers come only from the documents you have loaded; ask about something they do not cover and it says so
• Every claim is cited, and clicking a citation jumps to the exact passage
• Summarise, explain a selected passage, or have it suggest annotations
• Ask it to rewrite the document and review the changes before anything is applied

Choose where it runs:
• Ollama: a model running on your own computer. Nothing leaves your machine.
• Claude, ChatGPT or Gemini: using an API key you supply yourself

PRIVACY BY DEFAULT
• Your documents, annotations and settings never leave your computer
• No analytics, no telemetry, no advertising, no account required
• Cloud features are off until you turn them on with your own API key, and each one states plainly where your data goes
• API keys are encrypted with Windows DPAPI and readable only by your Windows account
• Open source: every claim above can be verified in the code

Created by Narashiman Krishnamurthy.
Free for personal, non-commercial use.
```

## Notes for certification

*(Submission options → Notes for certification; replace the old text. Two things in the old notes are no longer true: Ctrl+S now keeps you in the editor, and a new document asks for a file name after 30 seconds)*

```
HOW TO TEST THIS APP

No account, sign-in, licence key or internet connection is required for the core functionality.

1. The app opens with a welcome document already loaded.
2. READING AND ANNOTATING: select any text in the document. A small toolbar appears above the selection. Click a coloured circle to highlight, or the speech bubble to attach a comment. Press Ctrl+Shift+C to see the annotations panel. Press F9 for reader mode.
3. EDITING: press Ctrl+E to switch to the source editor. Select text there and a formatting toolbar appears. Press Ctrl+S to save; you stay in the editor. Ctrl+Shift+V returns to reading view.
4. AUTOSAVE: after 30 seconds of changes to a new, unnamed document, the app asks once for a file name so it can save automatically. Cancelling is fine; a recovery copy is kept instead.
5. COMPARING: File > Compare documents. Choose "Load two new files to compare" and pick any two text or Office files.
6. CONVERTING: press Ctrl+Shift+M and choose any PDF, Word, Excel or PowerPoint file, then press Convert. This runs entirely offline.
7. PRINTING: Ctrl+P opens the standard Windows print dialog.

OPTIONAL FEATURES THAT ARE EXPECTED TO SHOW AS UNAVAILABLE

The AI panel (Ctrl+Shift+A) and the "Explain" button in Compare documents need either Ollama installed locally, or an API key from Anthropic, OpenAI or Google that the user supplies. On a clean test machine they will report "Ollama not running on this computer" or "No API key saved". This is intended; the rest of the app is fully functional without them.

Cloud OCR and audio transcription need a user-supplied API key and will say so. Offline OCR works with no key.

PRIVACY

The app collects no data, has no analytics and no server. Cloud features are off by default and each displays what is sent and where before it is used.
```
