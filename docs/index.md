# Suprasūtā Markdown Notes

**A Markdown viewer, editor, annotator and document converter for Windows 11.**

Highlight and comment on your documents — and have the annotations saved *inside*
the Markdown file, so it still opens correctly anywhere else.

[Download](https://github.com/Narashiman-K/Markdown-Notes-windows/releases) ·
[Source code](https://github.com/Narashiman-K/Markdown-Notes-windows) ·
[Privacy policy](privacy.md)

---

## What it does

**Read and annotate.** Highlights in five colours, underline, strikethrough and
comments. Each one is written into the file as a standard HTML tag, so an
annotated document stays a perfectly valid `.md` that GitHub, VS Code or Obsidian
will still render.

**Edit.** A proper source editor with syntax highlighting, and a formatting bar
that appears when you select text. Save returns you to reading view.

**Convert almost anything to Markdown.** PDF, Word, Excel, PowerPoint, OpenDocument,
EPUB, CSV and plain text — all converted entirely on your own computer, with no
account and no internet connection. Images can be read via offline OCR or a cloud
service. Audio can be transcribed via a cloud service.

**Ask questions about your documents.** An AI panel that answers *only* from the
documents you have loaded, cites the passage it used, and tells you plainly when
something isn't covered rather than inventing an answer. It can run entirely on
your own machine using a local model.

## Privacy in one line

Your documents never leave your computer unless you personally switch on an
optional cloud feature and supply your own API key.
