## Description

*(max 10,000 characters; replace the whole description; about 3,800)*

```
Suprasuta Markdown Notes turns Markdown from something you write into something you can read, listen to, study, mark up, compare and think with.

Most editors make you choose between reading and annotating. This one lets you highlight a passage, attach a comment, and still hand the file to someone who has never heard of this app, because every annotation is written into the Markdown itself as a standard HTML tag that GitHub, VS Code, Obsidian and every other renderer already understand.

WRITE THE WAY YOU LIKE
• Doc Editor: write formatted text like a word processor, with a Word-style toolbar and a right-click menu; the file is saved as clean Markdown underneath
• Edit mode: a full Markdown source editor with live preview, syntax highlighting and a formatting bar
• Table editor: build and edit tables in a grid, or click straight into a cell on the page
• Diagrams: flowcharts, timelines, mind maps and more, drawn from a few lines of text
• Table of contents that keeps itself up to date
• Undo and redo for every change; version history keeps every save so you can restore an earlier version
• AutoSave every 30 seconds, with recovery copies so unsaved work survives a crash

READ, LISTEN AND STUDY
• Read aloud with natural voices and each sentence highlighted; choose a reading style and speed, see your words per minute, set a sleep timer
• Play your own audiobook (.m4b or .mp3) with the text highlighted in sync
• Dictation: type with your voice, free and offline
• Reader mode (F9): distraction-free reading with text size, line width, spacing and page colours, and read aloud built in
• Mind map of any document, chapter by chapter, with key ideas and summaries on each card
• Study panel: question cards from the book, a quiz that remembers what you knew, your highlights as cards, tags and search, export to Anki or a spreadsheet

READ AND ANNOTATE
• Highlight in five colours, underline, strike through, and attach comments
• Annotations are saved inside the .md file: no sidecar files, nothing to lose
• Export your annotations and load them back onto any copy of the document
• Page view shows converted documents at their original page size, with page numbers

COMPARE AND MERGE
• See every difference side by side or inline, with the changed words marked
• Take changes across, edit either side, and export the comparison
• Merge several documents into one, and remove repeated paragraphs

CONVERT ALMOST ANYTHING TO MARKDOWN
• PDF, Word, Excel, PowerPoint, OpenDocument and EPUB, with pictures, working contents links and page numbers
• Text and data: TXT, CSV, TSV, JSON, YAML, XML, HTML, RTF, subtitles and source code
• Scanned PDFs and photos: text read offline in English, Kannada and Hindi
• Every document format is converted on your own computer

ASK YOUR DOCUMENTS
• Answers come only from the documents you have loaded, with every claim cited
• Summarise, explain a passage, suggest annotations, or rewrite with changes to review
• Distil a book into key points, quotes and how to apply each chapter
• Turn a website or a code folder into documentation
• Runs on your own computer with Ollama, or with your own Claude, ChatGPT or Gemini key

WORK WITH YOUR CLOUD FOLDERS
• Open from and save to OneDrive, Google Drive, Dropbox, iCloud and Box folders on your PC

PRIVACY FIRST
• Your documents, annotations and settings stay on your computer
• Read aloud and dictation run on your computer; their voice models download once
• Optional anonymous usage statistics (feature names only, never what you write), switched off with one click in Help
• No account, no advertising; cloud AI only with your own key
• Open source: every claim above can be checked in the code

Created by Narashiman Krishnamurthy.
Free for personal, non-commercial use.
```

## Notes for certification

*(Submission options → Notes for certification; replace the old text)*

```
HOW TO TEST THIS APP

No account, sign-in, licence key or internet connection is required for the core functionality.

1. The app opens with a welcome document already loaded.
2. READING AND ANNOTATING: select any text. A small toolbar appears above the selection: click a coloured circle to highlight, or the speech bubble to add a comment. F9 opens reader mode.
3. DOC EDITOR: click "Doc Editor" in the toolbar (beside View, Edit, Read). Click into the text and type; use the bar above the page or right-click for formatting.
4. EDIT MODE: Ctrl+E opens the Markdown source editor; Ctrl+S saves and stays in the editor.
5. READ ALOUD: click "Read aloud" and press the play button. The first time, the natural voice downloads once (about 310 MB) from huggingface.co; the text is highlighted as it is read.
6. DICTATION: click "Dictate" and allow the microphone. The speech model downloads once from huggingface.co; speech is recognised on the device.
7. MIND MAP: click the brain icon (Alt+M); "Study" opens the quiz and question cards.
8. CONVERTING: Ctrl+Shift+M and choose any PDF, Word, Excel or PowerPoint file. This runs offline.
9. COMPARE: File > Compare documents.

OPTIONAL FEATURES THAT ARE EXPECTED TO SHOW AS UNAVAILABLE

The AI panel (Ctrl+Shift+A), the AI tools in the AI menu and "AI cards" in the mind map need Ollama installed locally or a user-supplied API key from Anthropic, OpenAI or Google. On a clean test machine they report that no AI is connected. This is intended; everything else works without them.

PERMISSIONS AND NETWORK

The microphone is used only for dictation, when the user starts it. The app downloads voice and speech models from huggingface.co on first use, and may send anonymous feature-usage counts (no document content) to PostHog in the EU, which the user can switch off under Help > Send anonymous usage statistics.
```
